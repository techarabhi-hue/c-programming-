# Fundamentals of C

Basic C programs from the Fundamentals of C class exercise.

## Programs

1. `01_hello_world.c` - Prints Hello World.
2. `02_integer_input.c` - Reads and displays an integer.
3. `03_character_input.c` - Reads and displays a character.
4. `04_add_two_integers.c` - Adds two integer values.
5. `05_double_operations.c` - Adds and multiplies two double values.

## Compile and Run

Using GCC:

```bash
gcc 01_hello_world.c -o hello
./hello
```

Replace the filename with the program you want to compile.
